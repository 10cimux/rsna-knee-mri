# Portefólio — Data Scientist e Computer Vision

O objetivo deste projeto é mostrar trabalho verificável: construção de uma baseline,
auditoria de dados médicos, avaliação estatística, comparação controlada de modelos
e inferência reprodutível sob restrições computacionais.

A EXP04 desenvolvida no projeto atingiu Public Score 0,732. A reprodução atribuída
do modelo público Raptor atingiu 0,924. A EXP12 preservou previsões nos testes
executados, mas não foi submetida antes do encerramento. Não reivindicamos vitória,
classificação final, benefício clínico nem autoria do Raptor.

As experiências que falharam fazem parte do estudo de caso. O repositório inclui
código e testes sintéticos executáveis, sem imagens, relatórios, identificadores
reais, labels ou pesos. Ver README para instalação e limites de reprodução.
